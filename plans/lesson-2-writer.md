# Урок 2. Текстові документи (LibreOffice Writer)

**Time:** 35 min — theory 10, step-by-step walkthrough 25 (test is separate, not counted)
**Goal:** the student can create a neat one-page document with headings, a list, a photo and a table, and send it as PDF.
**Sample files:** `files/text.txt` (plain text to paste, so no one wastes time typing), `files/photo.jpg` (a fictional portrait made for the lesson)
**Through-line:** everything is built around one real-life document, a **simple CV (резюме)**

## Theory

### On the lesson page (1 picture)

- Paragraph (Enter) and page
- Why styles matter (headings and the document outline)
- Formats:
  - ODT: native format
  - DOCX: for people who use MS Word
  - PDF: for sending, looks the same everywhere
- Hotkeys table: Ctrl+C / V / X / Z / S / B / I / U

### «Детальніше» page (`more.md`, optional, not in the test) ✅

Written: 8 sections (editor vs processor, what is inside ODT/DOCX/PDF with a measured size chart, Enter vs Shift+Enter, fonts and sizes, page format/margins, automatic table of contents, compatibility with MS Office, more hotkeys); pictures and chart from `recording/more_l2.py`. Original topic list:

- Text editor (Notepad) vs word processor (Writer)
- New line inside a paragraph (Shift+Enter) vs new paragraph (Enter)
- Hidden formatting marks ¶ (Ctrl+F10)
- Fonts with and without serifs: what to use where
- Page margins and orientation
- Automatic table of contents from the heading styles
- LibreOffice and MS Office: what can look different

## Додаткове завдання (необов'язкове)

_Not required and not done in class. If a student submits it, the teacher grades it. Marked in the book as «Необов'язково»; the book also explains how to submit it._

Make your own CV (or a sample person's CV):
- the name as «Заголовок 1»;
- sections as «Заголовок 2»;
- a list of skills;
- a table of education and work;
- a photo;
- export it as PDF.

## Test topics (10 questions)

1. What a paragraph is (Enter)
2. Hotkey for bold
3. Why to use heading styles
4. Hotkey to copy and paste
5. How to make a numbered list
6. Which format to use when sending a document that must look the same everywhere (PDF)
7. ODT vs DOCX
8. What a red wavy underline means
9. How to insert a table
10. How to change a picture's size without distorting it (drag the corner)
