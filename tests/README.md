# Тести: як створити Google Форму

1. Відкрийте **script.google.com** → **Новий проєкт**.
2. Видаліть код у редакторі та вставте вміст файлу `lesson-N.gs`.
3. Натисніть **Виконати** (функція `createForm`). Під час першого запуску Google попросить дозволу працювати з Формами: **Переглянути дозволи** → оберіть акаунт → **Дозволити**.
4. Унизу, у **Журналі виконання**, з'являться посилання:
   - **коротке** для студентів (forms.gle/…) — його вставляємо в розділ «Тест» уроку;
   - повне для студентів (про запас);
   - для редагування форми.

Форма вже налаштована як тест: 1 бал за запитання. Адреси e-mail не збираються. Перші два поля обов'язкові й не оцінюються: «Прізвище та ім'я» та «Група».

Запитання змінюйте у `lesson-N.json`, потім запустіть `python3 tests/build.py N`. Скрипт і ключ (`lesson-N-key.md`) згенеруються заново.
