# Workflow

The process has 6 stages. **✋ marks a point where the user approves before work continues.**

## Stage 1: environment

1. Install the packages (system-wide or inside the project; still to be decided).
2. Local Ukrainian locale in `recording/locale/` (done).
3. Each program gets a **project-local profile**, so the user's own settings are never touched:

   | Program | How the profile is kept local |
   |---|---|
   | Krita | `XDG_CONFIG_HOME` and `XDG_DATA_HOME` → `recording/profiles/krita/` |
   | LibreOffice | `-env:UserInstallation=file://…/recording/profiles/lo` |
   | Firefox | `--profile recording/profiles/firefox` (starts clean, without uBlock) |
   | Geany | `-c recording/profiles/geany`; run in a terminal (xterm) |

4. Each profile is prepared once with the same settings:
   - Ukrainian interface
   - no welcome or "tip of the day" windows
   - large readable font (zoom 125%)
   - window maximized

## Stage 2: trial clip ✋

- Record L1-03 («Обираємо пензель і колір») end to end.
- The user approves:
  - the click highlight (red ripple)
  - the box around buttons
  - the caption style and position
  - the speed
  - GIF size and quality
- These settings are then used for all clips.

## Stage 3: lesson texts ✋

- Write `src/lesson-N-*/index.md` in Ukrainian, following `plans/lesson-N-*.md`.
- Put clip placeholders where the media will go.
- Style:
  - short sentences, "ви" form
  - one action per step
  - bold for button names: **Файл → Експортувати**
  - extra theory goes to the lesson's separate page `more.md` («Детальніше»): longer text, diagrams, charts and real examples generated by `recording/more_lN.py`, and a «Джерела» line with checked links in every section
- The user reviews one lesson before the rest are written.

## Stage 4: recording

Per clip, from `recording/`:

```
scenarios/L1-03.py   →  run.sh L1-03  →  raw/L1-03.mkv + raw/L1-03.events.json
                                       →  annotate.py  →  src/lesson-1-graphics/media/L1-03.gif (+ .mp4 if > 20 s)
```

1. **Scenario** (`scenarios/<ID>.py`): a short list of steps using a small helper:
   - `caption("Крок 1: …")`, `click(x, y)`, `drag(...)`, `type("…")`, `key("ctrl+z")`, `wait(1.5)`
   - Positions are found from a screenshot of the prepared window, and the program window always has the same size.
   - Every step is logged with a timestamp.
2. **Record** (`run.sh`):
   - start Xvfb `:99` at 1280×800 and openbox;
   - launch the program with the local locale and profile;
   - `ffmpeg -f x11grab` with the cursor visible;
   - play the scenario, then stop.
3. **Annotate** (`annotate.py`):
   - read the event log;
   - build an ffmpeg filter: a ripple at each click, a box around the target, and a caption bar with a Ukrainian font (Noto Sans / DejaVu Sans);
   - trim the dead time at the start and end.
4. **Export:**
   - GIF via gifski: 960 px wide, 12–15 fps, aim for < 3 MB
   - MP4 (H.264, no sound) for long clips
5. **Check:**
   - extract 4–6 frames and look at them: right menu? readable? caption timing correct?
   - if something is off, fix the scenario and record again.
6. **Annotated screenshots** (L1-01 and others like it) use the same pipeline with a single frame, plus numbered markers.

Web and AI clips (L3-09…12, L4-08…13) need the internet and are **not identical between runs**:
- Each clip is recorded several times and the clearest take is kept.
- AI answers are read in full before a take is accepted.
- News pages are checked for unsuitable ads.

## Stage 5: tests ✋

- `tests/lesson-N.json`: the questions (single source of truth). Questions come only from the lesson page (theory and clips), never from the «Детальніше» page
- `tests/build.py` creates from it:
  - `tests/lesson-N.gs`: the Google Apps Script:
    - quiz mode
    - no email collection, no sign-in
    - «Прізвище та ім'я» and «Група» required, not graded
    - 10 × 1 point
    - answer order shuffled
  - `tests/lesson-N-key.md`: the answer key for the teacher
- The user runs one `.gs` in their Google account to confirm it works. Then the Form links are added to each lesson's «Тест» section.

## Stage 6: book build and review ✋

- `mdbook serve` for a live preview, then `mdbook build`, which puts the finished site in `book/`.
- Checks:
  - every clip loads
  - no broken links
  - pages are readable on a phone
  - total size of the media
- Final read-through by the user.

## File naming

- Clips: `L<lesson>-<nn>.gif|mp4|png`; the source scenario has the same ID.
- Everything under `recording/` and `tests/*.json` can be regenerated; only `src/` goes into the book.
